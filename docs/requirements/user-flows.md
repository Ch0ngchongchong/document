# 핵심 사용자 흐름

> **저장 위치:** `docs/requirements/user-flows.md`

> 첫 데모에서 보여줄 흐름을 **하나만** 정합니다. 어제 그린 상태 전이(`docs/domain/03-rules-states-llm.md` 3-2)를 **처음부터 끝까지 한 번 지나가는** 정상 경로여야 합니다. 이 흐름이 첫 데모(3주차)에서 보여줄 그 흐름입니다.
> 이 단계에서는 Claude를 쓰지 않습니다. `>`로 시작하는 안내 문장은 지워도 됩니다.

## 연결된 상태 전이
03-rules-states-llm.md의 핵심 대상:
지나가는 상태: 업로드 대기 → 판독 중 → 직원 확인 대기 → 재고 반영 완료 (4개 이상)

## 첫 데모에서 보여줄 흐름 (1개)

| 순서 | 누가 | 무엇을 하는가 | 이때 상태 | LLM 관여 |
| --- | --- | --- | --- | --- |
| 1 | 시스템 | 발주 건이 입고 대기가 됨 | 업로드 대기 | 없음 |
| 2 | 직원 | 거래명세서 사진·PDF를 업로드함 | 업로드 대기 → 판독 중 | 없음 (업로드만) |
| 3 | 시스템 | OCR+LLM으로 명세서를 정리하고 발주와 매칭함. 다른 줄·불확실 값을 표시함 | 판독 중 → 직원 확인 대기 | 있음 (OCR+LLM) |
| 4 | 직원 | 일반 건(발주와 모두 일치)을 확정함 | 직원 확인 대기 | 없음 |
| 5 | 시스템 | 확정된 수량·단가를 재고에 반영함 | 재고 반영 완료 | 없음 |
